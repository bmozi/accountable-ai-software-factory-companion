# Repository instructions

## Required Git and publication handoff

Author-directed September 23, 2026: at the end of substantive work, review the
actual diff and new files, run applicable validators, commit the reviewed work,
push the intended branch, then fetch and verify local HEAD equals upstream and
inspect working-tree status again. This is standing authorization unless the
current session limits it. Do not include another active agent's changes.
Report remaining local-only work explicitly; do not silently leave it behind.
Follow this repository's artifact policy and preserve historical review evidence.
For books, compare current manuscript inputs and membership against the selected
release's recorded inputs, and compare upload/snapshot hashes. Record unpublished
changes separately. Git synchronization does not establish publication readiness,
retailer upload, human reader validation, or physical proof quality. Preserve the
mandatory exact-final-file visual review gate before promotion/readiness claims.
The shared toolkit's `BOOK-REPOSITORY-HANDOFF.md` and
`book_production/audit_repository.py` describe the repeatable audit.
