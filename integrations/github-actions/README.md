# GitHub Actions integration

Copy `accountability-gates.yml` into `.github/workflows/` in a pilot repository,
or adapt its three commands to your existing CI. Pin third-party actions to full
commit SHAs under your organization’s supply-chain policy before production use.

This workflow proves contract validation, the twenty-four failure obligations,
and one complete local effect. It does not grant production authority, store
credentials, or claim that generic tests satisfy a domain-specific evidence
floor. Add your own evaluators and protected-environment approvals at those
boundaries.
