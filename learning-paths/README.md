# Role-Based Learning Paths

Each path uses the same accountable-factory spine but asks a different person
to own the decisions only that role can legitimately make. A role path is not
permission to work alone.

## Engineer or technical lead — four sessions

1. Run the failure-oriented journey in [`START-HERE.md`](../START-HERE.md).
2. Implement one Work Order and failing acceptance test using the
   [`minimum viable factory guide`](../implementation/minimum-viable-accountable-factory.md).
3. Run drills 1–4 in the [`failure laboratory`](../exercises/failure-laboratory.md).
4. Produce a candidate, evidence package, disposition, and receipt that another
   person can reconstruct without a transcript.

**Completion evidence:** one unsafe state transition is rejected, one stale
verdict is invalidated, and one recovery path is exercised.

Before expanding authority, complete the
[`AI Practice and Guardrail Guide`](../workforce/ai-practice-and-guardrail-guide.md)
for the specific work class. It is a formation instrument, not an employee
ranking.

## Architect or platform owner — three workshops

1. Complete the
   [`factory architecture decision guide`](../templates/factory-architecture-decision-guide.md).
2. Draw current responsibility placement using the
   [`visual guide`](../diagrams/accountable-factory-visual-guide.md).
3. Write two reversible decisions using the
   [`architecture decision starters`](../decisions/architecture-decision-starters.md):
   one about execution topology and one about authoritative state.

**Completion evidence:** replace one component on paper without losing intent,
authority, evidence, recovery, or outcome history.

## Security, privacy, or risk leader — two workshops and one drill

1. Complete the [`threat-model workbook`](../templates/factory-threat-model.md)
   for one work class.
2. Map consequence to evidence with the
   [`risk-to-evidence matrix`](../templates/risk-to-evidence-matrix.md).
3. Run drills 2, 5, and 7 in the
   [`failure laboratory`](../exercises/failure-laboratory.md).

**Completion evidence:** a persuasive producer cannot expand its own authority,
hide evaluator conflict, or convert a lost response into a blind retry.

## Engineering executive or factory sponsor — ninety days

### Days 0–30: Bound the promise

- Run the [`accountable-factory diagnostic`](../assessment/accountable-factory-diagnostic.md).
- Select one frequent, reversible work class.
- Complete the factory charter, decision-rights matrix, and outcome scorecard.

### Days 31–60: Prove the unhappy path

- Establish the baseline and countermetrics.
- Run the reference factory and at least four failure drills.
- Publish support, exception, degradation, and recovery behavior to pilot users.

### Days 61–90: Decide, do not celebrate

- Run the [`comparative pilot protocol`](../templates/comparative-pilot-protocol.md).
- Review the [`factory balance sheet`](../templates/factory-balance-sheet.md).
- Expand, hold, narrow, redesign, or stop one authority dimension.

**Completion evidence:** a dated decision memo reports denominators, failures,
human load, costs, outcome evidence, dissent, and the next authority boundary.

## Finance, product, or consequence owner — two reviews

1. Follow the [`Meridian Ledger worked trace`](../examples/meridian-ledger-complete-trace.md)
   and identify where cheap generation creates continuing obligations.
2. Complete the outcome scorecard, comparative pilot, and factory balance sheet
   with engineering, operations, and risk owners present.

For a sourcing decision, add the
[`AI-Native Build-versus-Buy Calculator`](../leadership/ai-native-build-versus-buy-calculator.md).

**Completion evidence:** the decision distinguishes candidate cost from total
cost and an experiment from an accepted operating obligation.

## Facilitator or educator — six meetings

Use three chapters per meeting from the
[`chapter workbook`](../study-guides/chapter-workbook.md) or assign the deeper
[`individual chapter guides`](../study-guides/chapters/README.md). Require each learner
to bring one artifact, one failure example, and one decision they would reverse
under different evidence. End with a cross-role review of the complete trace.
