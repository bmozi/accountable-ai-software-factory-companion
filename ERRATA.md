# Errata

No confirmed book errata have been recorded through companion version 1.1.0.

Version 1.1 replaces the companion’s v1.0 split teaching models with one
canonical executable contract. This is a companion implementation correction;
it does not change the already-published book.

When reporting a possible error, include the companion release or commit,
file, heading or line, expected behavior, observed behavior, and any evidence
needed to reproduce it. Do not include credentials, customer data, private
source code, or vulnerability details in a public issue.
