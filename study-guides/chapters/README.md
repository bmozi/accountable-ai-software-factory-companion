# Companion Learning Guide

This guide preserves the deeper instructional apparatus without making *The
Accountable AI Software Factory* read like a textbook. It can support individual
study, leadership workshops, engineering cohorts, university courses, and
facilitated organizational transformation.

Each chapter guide contains:

- four measurable learning objectives;
- five chapter-grounded key terms;
- four review questions;
- two discussion questions;
- three artifact-producing exercises, including one Challenge exercise;
- explicit deliverable and assessment criteria.

The book remains independently useful. The guide is an optional second layer
for readers who want to practice, teach, or operationalize the material.
