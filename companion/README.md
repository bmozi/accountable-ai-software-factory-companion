# Published Book 3 Paths

The published edition of *The Accountable AI Software Factory* refers to
reader artifacts with `companion/...` paths. This directory preserves those
paths as a stable contract.

The maintained artifacts live in [`templates/`](../templates/). Each file in
this directory points to its maintained counterpart so readers can follow the
book exactly while existing links to `templates/...` continue to work.

These paths are checked automatically before a companion release.
