# Comparative Factory Pilot Protocol

Use this protocol with Chapters 15 and 18 to test one bounded claim: for one
declared work class, does the accountable-factory path improve justified
outcomes relative to the organization's current process without unacceptable
quality, security, recovery, cost, or human-load consequences?

This protocol cannot prove universal superiority. It can establish a bounded,
dated result under described conditions.

## Comparison paths

Where ethical and operationally feasible, compare:

1. the current human-owned process;
2. an ordinary AI-assisted or coding-agent process using existing controls;
3. the accountable-factory process using durable intent, bounded authority,
   independent evidence, disposition, receipts, and outcome observation.

Do not weaken the evidence floor for one path to make it cheaper. If controls
differ, report the difference as part of the treatment.

## Pre-registration

Before observing results, record:

- the hypothesis and decision the pilot will inform;
- eligible and excluded work;
- sampling and assignment method;
- baseline period and known confounders;
- authority granted in each path;
- primary metric and countermetrics;
- outcome window and minimum sample;
- stop and harm thresholds;
- missing-data treatment;
- who may declare effective, ineffective, insufficient, or harmful; and
- what result permits continuation, reduction, or one-dimensional expansion.

## Measurement set

| Dimension | Measures |
| --- | --- |
| Flow | Elapsed lead time, active time, queue time, abandonment |
| Human load | Context preparation, review, interruption, escalation, repair |
| Quality | Rework, escaped defects, severity, acceptance-criterion coverage |
| Control | Refusals, denied effects, stale evidence, exceptions, overrides |
| Recovery | Partial or indeterminate attempts, duplicate effects, time to reconcile |
| Economics | Provider, compute, tool, evidence, storage, review, incident, and platform cost |
| Outcome | Declared beneficiary measure and observation disposition |
| Experience | Comprehension, confidence, fatigue, workarounds, perceived agency |
| Estate | Dependencies, generated surface, ownership, retirement obligations |

Record denominators and work mix. “Twenty percent faster” is uninterpretable
without knowing which work entered, which was refused, and how consequence
differed.

## Analysis

Separate:

- completion from justified completion;
- mean from tail behavior;
- setup from steady-state work;
- compute cost from total cost;
- confidence from evidence accuracy;
- pre-release quality from observed outcome; and
- correlation from plausible attribution.

Inspect the worst failures individually. Averages can conceal one authority or
tenant breach that changes the deployment decision.

## Decision memo

The memo must report:

1. participants, work, period, and conditions;
2. path differences and compliance with protocol;
3. results with denominators and uncertainty;
4. exclusions, missing data, and confounders;
5. worst failures, stops, and recoveries;
6. outcome and countermetric dispositions;
7. participant perspectives, including dissent;
8. cost and support burden;
9. the decision to stop, continue, narrow, repair, or expand one dimension; and
10. which learning, if any, is proposed for separate admission.

Publish or preserve negative and inconclusive results. A comparison that can
only justify expansion is a sales exercise, not an operating experiment.
