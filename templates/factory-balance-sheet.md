# Factory Balance Sheet

Use this operating instrument with the economics interludes and Chapters
14–18. It is not a financial statement under an accounting standard. Its job
is to make the assets, scarce capacities, liabilities, exposures, and future
obligations created by abundant software visible.

Complete it quarterly and before a material authority expansion, provider
commitment, or portfolio funding decision.

|  |  | users / data / interface / contractual promise |  |  |  |

An experiment should expire unless named authority accepts the operated
obligation. Conversion is a portfolio decision, not a side effect of a good
demonstration.

## Capital-allocation decision

| Investment | Constraint addressed | Expected outcome effect | Countermetric | Evidence window | Reallocation trigger |
| --- | --- | --- | --- | --- | --- |
| More execution capacity |  |  |  |  |  |
| Evidence, review, integration, or recovery |  |  |  |  |  |

End with explicit dispositions: preserve, renew, narrow, fund, repair, exercise
an exit, convert an experiment, let it expire, retire a capability, or collect
missing evidence. Every decision names an owner, evidence window,
countermetric, and reversal condition.

## Fictional Meridian Ledger snapshot

Candidate cost is falling while evidence-complete queue age and domain-review
time rise. Two tools have no outcome owner. One provider controls most
execution and the only readable copy of some attempt detail. Three experiments
acquired users without an obligation-conversion review.

The company does not report lower candidate cost as factory return. It funds
evidence automation and recovery, assigns or retires the unowned tools, exports
the decision record, and forces the experiments through conversion or expiry.
This is instructional, not measured evidence.
