# Executable Teaching Core

This standard-library Python curriculum uses the canonical package at the
repository root. It demonstrates a durable Work Order, enforceable policy,
compare-and-set transitions, artifact-bound evidence, producer/evaluator
separation, budget and lease conservation, reconcile-before-retry, receipts,
outcomes, and governed learning. Its local Git adapter is a real reversible
effect, not a mocked success.

Run:

```bash
cd ../..
PYTHONPATH=. python3 -m unittest discover -s reference-factory/example -p 'test_*.py'
```

Or run the tests and complete canonical journey from the parent directory:

```bash
../run-reader-journey.sh
```

The twenty-four tests correspond one-for-one with the suite in the parent
directory. The implementation remains teaching code: supply enterprise
identity, authentication, sandbox isolation, secret handling, tenant controls,
domain evaluators, and protected deployment approvals before consequential use.
